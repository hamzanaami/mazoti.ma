# Glossary (FR / AR / EN)

Arabic terms are common usage and need review by a native speaker before they appear in the product.

| English | Français | العربية |
|---|---|---|
| Diesel (gasoil) | Gasoil | الغازوال |
| Super unleaded gasoline (SSP) | Super sans plomb (SSP), essence | البنزين |
| Pump price | Prix à la pompe | سعر المحطة / الثمن عند المضخة |
| Price liberalisation | Libéralisation des prix | تحرير الأسعار |
| Internal consumption tax (TIC) | Taxe intérieure de consommation (TIC) | الضريبة الداخلية على الاستهلاك |
| Value added tax (VAT) | Taxe sur la valeur ajoutée (TVA) | الضريبة على القيمة المضافة |
| Competition Council | Conseil de la concurrence | مجلس المنافسة |
| Settlement agreement | Accord transactionnel | اتفاق تصالحي |
| Wholesale distributor | Société de distribution en gros | شركة التوزيع بالجملة |
| Service station | Station-service | محطة الوقود |
| Independent station manager | Gérant libre | المسير الحر |
| CIF quotation | Cotation CIF | سعر CIF المرجعي |
| Purchase cost | Coût d'achat | كلفة الشراء |
| Cession price | Prix de cession | سعر التفويت |
| Gross margin | Marge brute | الهامش الإجمالي |
| Net margin | Marge nette | الهامش الصافي |
| Pass-through | Répercussion / transmission | انتقال الأسعار |
| Asymmetric price transmission | Transmission asymétrique des prix | انتقال غير متماثل للأسعار |
| Security stock | Stock de sécurité | المخزون الاحتياطي |
| Fortnightly revision | Révision bimensuelle | المراجعة نصف الشهرية |
| Refined products | Produits raffinés | المواد البترولية المكررة |
| Platts quotation | Cotations Platts | أسعار منصة بلاتس |
